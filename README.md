# Ace Deathshead in Doom
A skin for ZDoom that replaces Doomguy with Ace Deathshead, my SS14 moth character.
Features full rotation sprites, SS14 sounds and mugshot!
This project was inspired by the [Spot in Doom](https://github.com/Tofi-Dev/Spot-In-Doom) project by [Tofi](https://github.com/Tofi-Dev).
